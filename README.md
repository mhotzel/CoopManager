## Environment variables

All configuration parameters can be set by environment variables. 
Alternatively, it is possible to set them using the `.env` file in 
the root directory. Keep in mind, that it is recommended, to prefer 
environment variables over configuration files [https://12factor.net](https://12factor.net).

**SECRET_KEY**
This variable is necessary to generate secure password hashes, sign cookies and so on.
